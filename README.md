# NOVA — Modern Fitness Studio

Premium conversion-focused landing page demo for the Vadrivo portfolio.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Notes
- React + TypeScript + Vite.
- Uses Framer Motion and Lucide React.
- Demo imagery is sourced from Unsplash URLs.
- The booking form is a front-end demo and can be connected to Formspree, Resend, a CRM, or another real booking workflow later.
